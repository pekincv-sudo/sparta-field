# Попередня комерційна пропозиція — версія 1.0.50

1. Відкрийте об’єкт → «3 КП» → «Обрати з номенклатури».
2. Знайдіть товар за назвою, моделлю, артикулом, категорією або брендом. Нульовий залишок не перешкоджає підготовці КП.
3. Укажіть кількість і ціну для клієнта. Довідкова ціна тієї самої валюти підставляється з каталогу, її можна змінити. Якщо валюта каталогу інша, введіть власну ціну у валюті КП: автоматичної конвертації немає.
4. Натисніть «Додати до КП». За потреби використайте «Додати власну позицію» для обладнання, матеріалу або послуги, якої ще немає у номенклатурі.
5. У збереженій позиції розгорніть «Змінити кількість, ціну або опис». Зміни стосуються лише цієї КП. Номенклатура та її ціни не змінюються.
6. Укажіть попередню вартість монтажу в розділі «Вартість монтажних робіт».
7. «Друк / PDF» формує клієнтську пропозицію: обладнання, кількість, ціни, монтаж і загальна оцінка. Закупівельні ціни та зарплати клієнтові не показуються.

КП — попередній документ. Додавання, редагування й видалення її позицій не створюють резервів, складських документів, платежів або боргу та не змінюють суму договору. Пропозиція зберігає власні описи й ціни; наступні зміни номенклатури їх не перераховують. Редагування монтажу у КП не змінює погоджену вартість робіт або зарплату бригади.

Після погодження внесіть остаточну суму окремо в «Договір». Матеріали плануються окремо; кнопка «Взяти план із КП» лише копіює план. Якщо у КП інша валюта або одиниця, складський товар автоматично не прив’язується: доберіть фактичне обладнання в матеріалах. Доставку, видачу та використання оформлюйте відповідними документами за фактом. КП сама нічого не списує.

Сумісність: попередні КП та договори збережено без переписування. Для старої КП без окремої оцінки монтажу показується попередня вартість; перша зміна КП фіксує її окремо. Старі автоматично заповнені суми договорів не обнуляються. Зміни бази даних для цієї версії не потрібні.
